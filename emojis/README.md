# Application Emoji
`cogs/application_emojis.py` の `EMOJI_FILES` に、Application Emoji名と画像ファイルの対応を定義してください。

### 幽境の激戦
Bot起動時にDiscord Application Emojiが未登録の場合のみ、Enka.Networkから取得してこのディレクトリへキャッシュします。

```text
https://enka.network/ui/UI_LeyLineChallenge_Medal_1.png
...
https://enka.network/ui/UI_LeyLineChallenge_Medal_6.png
```

取得した画像はリポジトリのUnlicense対象外です。画像の権利は各権利者に帰属します。
